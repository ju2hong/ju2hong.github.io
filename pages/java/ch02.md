### 1. 변수

- 변수는 프로그램이 데이터를 저장하기 위해 할당받은 메모리 공간을 의미합니다.
- 변수는 다음과 같은 형식으로 만들며, 변수를 만드는 것을 변수 선언한다고 합니다.

> 형식 자료형 변수명;

- 변수를 선언한 후 값을 넣어 저장하는 것을 초기화 라고 합니다.

> 자료형 변수명 = 값; //선언과 동시에 초기화

- 변수 선언과 동시에 초기화해도 되고 나중에 따로 해도 됩니다. 단, 사용하기 전에는 반드시 초기화 해야합니다.

### 2. 자료형

- 변수에 저장하는 값의 형태를 자료형이라고 합니다.
- 자바에는 8가지 기본 자료형이 있습니다
- 자바에는 8가지 기본 자료형이 있습니다

  | 자료형 | 키워드  | 값의 크기 |
  | ------ | ------- | --------- |
  | 정수형 | byte    | 1 바이트  |
  |        | short   | 2 바이트  |
  |        | int     | 4 바이트  |
  |        | long    | 8 바이트  |
  | 실수형 | float   | 4 바이트  |
  |        | double  | 8 바이트  |
  | 문자형 | char    | 2 바이트  |
  | 논리형 | boolean | 1 바이트  |

- 기본 자료형 외에도 참조 자료형이 있습니다. String이 여기에 속합니다. String은 문자열로 된 값을 표시할 때 사용합니다. 문자열은 자바에서 큰따옴표(")로 표시합니다.

### 3. 상수와 리터럴

- 상수는 저장한 값이 바뀌지 않는 변수를 말합니다.
